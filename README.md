# Οικόπεδα στους Εργάτες

Προσωρινός ελληνικός κατάλογος οικιστικής γης, σχεδιασμένος για κοινοποίηση ενός συνδέσμου μέσω Viber. Δύο κάρτες ανά σειρά στο κινητό, τρεις στο desktop, μεγάλα γράμματα, φίλτρα και επεκτεινόμενες κάρτες ακινήτων. Το κουμπί «Λεπτομέρειες» επεκτείνει την κάρτα σε όλο το πλάτος της σειράς, με σταθερό Χ και κλείσιμο στο τέλος. Οι ξεχωριστές διευθύνσεις ακινήτων παραμένουν διαθέσιμες. Google Maps από την κλειστή κάρτα, με επιλογές πηγών όταν διαφέρουν οι πινέζες.

Δημόσια διεύθυνση: https://arisconstantinou.github.io/ergates-land/

## Τοπική λειτουργία

Απαιτείται Node.js 20 ή νεότερο. Δεν απαιτούνται npm dependencies.

```sh
npm run dev
```

Η διεύθυνση είναι πάντοτε `http://127.0.0.1:5187/`. Η θύρα αποθηκεύεται στο `project.config.json`. Ο server αποτυγχάνει αν η θύρα χρησιμοποιείται· δεν μεταπηδά σε άλλη θύρα. Πριν από νέα εκκίνηση ελέγξτε αν λειτουργεί ήδη ο ίδιος server.

```sh
npm test
npm run build
```

Το `dist/` είναι αυτοτελές στατικό site. Το GitHub Pages δημοσιεύει επίσης απευθείας τη ρίζα του `master`, με `.nojekyll`. Δεν υπάρχουν backend, λογαριασμοί επισκεπτών, analytics ή φόρμες αποστολής δεδομένων.

Στο ForSale ανοίχθηκαν 198 μοναδικές αγγελίες από 9 σελίδες. Δεν υποκαθιστούμε την επιβεβαίωση διαθεσιμότητας με παλιό αποτέλεσμα αναζήτησης.

## Δομή και ενημέρωση

- `data/properties.json`: αυτοτελές αρχείο αναφοράς. Κάθε ακίνητο έχει σταθερό μοναδικό `id`, `sources`, `facts`, εικόνες, ενδείξεις πρόσβασης/ιδιοκτησίας, αποκλίσεις και τεκμηρίωση συγχώνευσης.
- `facts[field]`: τιμές και `sourceIds`, που παραπέμπουν σε αρχικό URL, ιστοσελίδα και χρόνο ελέγχου. Καμία κενή τιμή δεν συμπληρώνεται με εικασία.
- `images/`: πραγματικές εικόνες των δημόσιων αγγελιών, με προέλευση στο JSON. Δεν χρησιμοποιούνται φωτογραφίες stock. Οι εικόνες διατηρούν τα υδατογραφήματα και ανήκουν στους αντίστοιχους δικαιούχους.
- `app.js`, `index.html`, `property.html`, `styles.css`: επαναχρησιμοποιούμενη απόδοση καταλόγου και λεπτομερειών.
- `scripts/assemble-data.py` και `scripts/cache-images.py`: βοηθήματα της αρχικής έρευνας. Απαιτούν τα τοπικά, μη δημοσιευμένα ενδιάμεσα αρχεία του `research/`. Δεν απαιτούνται για build ή λειτουργία· για απλή ενημέρωση επεξεργαστείτε το τελικό JSON και επαναλάβετε ελέγχους.

Οι προφανείς επαναλήψεις ενώθηκαν με συνδυασμό περιγραφής, φωτογραφιών, αριθμών τεμαχίου και χαρακτηριστικών. Ίδιο εμβαδό μόνο του δεν χρησιμοποιήθηκε ως απόδειξη ταυτότητας. Κρατήθηκαν χωριστές αβέβαιες περιπτώσεις. Ρητά πωλημένα/αποσυρμένα ακίνητα και τα τεκμηριωμένα αντίγραφά τους αποκλείστηκαν. Το ιστορικό αποκλεισμών βρίσκεται στο `meta.excluded`.

Η ζητούμενη τιμή και ο ΦΠΑ εμφανίζονται χωριστά. Όταν υπάρχουν διαφορετικές τιμές εμφανίζεται εύρος. Το €/τ.μ. υπολογίζεται ανά πηγή, με το αντίστοιχο δημοσιευμένο εμβαδό. Για ασαφές εμβαδό μεριδίου δεν υπολογίζεται. Οι ημερομηνίες αγγελιών μπορεί να αντιστοιχούν σε αναδημοσίευση.

## Επαλήθευση

Επτά αυτοματοποιημένοι έλεγχοι δεδομένων: προέλευση, αποκλεισμοί, συγχώνευση/διατήρηση διαφορετικών ακινήτων, αντιφάσεις, πρόσβαση/μερίδια, μετρητές και αρχεία φωτογραφιών. Επιτυχές στατικό build.

Έλεγχος πραγματικού Chromium στις αναλύσεις 320, 390, 768 και 1440 px: χωρίς οριζόντια κύλιση, δύο κάρτες στα κινητά. Ελέγχθηκαν τα φίλτρα, η πλοήγηση, το gallery και όλες οι 69 σελίδες ακινήτων για overflow, συνδέσεις προέλευσης, αρχικές αγγελίες και μορφή `tel:`. Δεν έγινε πραγματική τηλεφωνική κλήση ή έλεγχος σε φυσικό iPhone/Android μέσα στο Viber.
